# 彩票选号助手（福彩 + 体彩）

- 网页：仓库设为 Public 后，Settings → Pages → Branch: main，文件夹 /docs，访问 https://passionsu-su.github.io/fucai/
- 数据：`docs/data/<玩法>.csv`（ssq 双色球、qlc 七乐彩、fc3d 福彩3D、dlt 大乐透、pl3 排列3、pl5 排列5、qxc 七星彩），每天北京时间 22:30 由 GitHub Actions 自动更新
